# Stack and Toolchain

Every dependency in [package.json](../package.json), why it is here, and which facade owns it.
Versions below are the exact ranges declared today; `npm run deps:check` reports drift.
Raw vendor imports outside the owner wrapper are an ESLint error — see
[context/package-boundaries.md](./package-boundaries.md).

Node `24.18.0` (`.nvmrc` / `.node-version`), npm `12.0.1` through Corepack
(`packageManager: npm@12.0.1`). Pinned `allowScripts` entries permit only reviewed native build
steps, explicitly deny MSW's nonessential postinstall, and make new install scripts fail closed.
Scoped `overrides` keep `postcss`, `brace-expansion`, `fast-uri`, `@swc/helpers`, and Next's
optional `sharp` dependency on compatible patched versions until their owners' ranges catch up. See
[memory/security-decisions.md](../memory/security-decisions.md).

## Script map

`dev` / `build` (Turbopack), `lint` (`--max-warnings=0` + error-only severity verifier),
`typecheck` (stable TypeScript 7 over app/test/node), `typecheck:compat` (TypeScript 6 API),
`test` / `test:coverage`, `test:e2e` / `test:a11y` / `test:visual`,
`security:audit` / `security:scan`, `quality:dead-code` / `quality:circular`,
`assets:social:generate` / `assets:social:check`, `gate:push` (the local/CI push gate), and
`validate` (push gate + e2e + Trivy). See
[rules/19-release-gates.md](../rules/19-release-gates.md) for what MUST pass when.

Rationale for each vendor choice is recorded in
[memory/package-decisions.md](../memory/package-decisions.md).
